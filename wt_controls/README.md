# War Thunder 手柄键位预设

`战争雷霆自动炸战区按键.blk` 是一份 War Thunder 键位设置导出文件（控制预设），其按键映射与本仓库 `common/gamepad.py` 中的虚拟手柄操作一一对应，保证自动轰炸流程按键正确。

键位说明：

| 功能             | 按键     |
| ---------------- | -------- |
| 批量投弹         | LB + X   |
| 切到投弹视角     | Y        |
| 切换视角         | RB       |
| 开关炸弹舱门     | LT + RT  |
| 继续 / 确认      | A        |
| 弹射跳伞         | 十字键上 |

若你的游戏键位与此不同，可通过 War Thunder 设置 → 保存按键/载入按键 导入此文件；或自行在游戏内调整键位，并同步修改 `../common/gamepad.py` 中对应的映射常量。
